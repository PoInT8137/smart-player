# Smart Player — план проекта

Видеоплеер для Android TV: быстрый, удобный с пульта, всеядный по форматам,
заточенный под торренты (через TorrServer) и работу в связке с Lampa.

## Как это работает с Lampa

Lampa торренты не качает сама: она отдаёт magnet в **TorrServer**, а тот
раздаёт файл как обычный HTTP‑поток (`http://127.0.0.1:8090/stream/...`).
Этот URL Lampa передаёт во внешний плеер через Android‑intent.

Наша задача — быть лучшим «внешним плеером» для такого потока:
- регистрироваться на `ACTION_VIEW` для `video/*`, `audio/*`, HLS/DASH;
- понимать extras в формате MX Player / VLC / Vimu (название, позиция,
  плейлист серий, заголовки, внешние субтитры);
- возвращать позицию и длительность обратно (`setResult`), чтобы Lampa
  отмечала прогресс и «просмотрено».

## Целевое устройство

- **Xiaomi TV Box S (3rd gen)** — Google TV, Amlogic, 4K / HDR10+ / Dolby Vision / AV1.
  Плеер ставится и тестируется здесь.
- Телевизор Samsung QE75QN90F (Tizen) — только экран. HDMI от приставки:
  важно корректно отдавать HDR и passthrough звука (Dolby/DTS) через HDMI.

## Технологии

| Что | Выбор | Почему |
|---|---|---|
| Язык / UI | Kotlin + Jetpack Compose | современно, быстро пишется, удобная работа с фокусом пульта |
| Движок | Media3 ExoPlayer 1.9 | аппаратное декодирование, HDR, passthrough звука, HLS/DASH |
| Аудио‑кодеки | FFmpeg decoder (сборка Jellyfin) | DTS, TrueHD, AC3/E‑AC3 там, где TV не умеет сам |
| Торренты | TorrServer (как в Lampa) | не изобретаем велосипед; позже — свой клиент к его API |
| minSdk | 23 (Android 6) | покрывает почти все TV‑боксы |

## Управление с пульта

| Где | Кнопка | Действие |
|---|---|---|
| Видео | OK | пауза / продолжить (на паузе открывается меню) |
| Видео | ◀ ▶ | перемотка ±10 с; если зажать — 30 с, потом 60 с |
| Видео | ▲ ▼ | открыть меню |
| Видео | Назад ×2 | выход (с возвратом позиции в Lampa) |
| Меню | ◀ ▶ на шкале | перемотка; OK — пауза |
| Меню | ▼ | к кнопкам: Серии, Звук, Субтитры, Настройки |
| Конец серии | OK | сразу следующая серия |
| Всегда | медиакнопки | ⏯ ⏪ ⏩ ⏮ ⏭ |

## Демо на эмуляторе

Скрипт `fake_torrserver.py` (в scratchpad сессии) раздаёт MKV по `http://127.0.0.1:8090/stream/...`,
порт пробрасывается в эмулятор: `adb reverse tcp:8090 tcp:8090`.
AVD: `TVBox` (Google TV, API 34 — как Xiaomi TV Box S 3).

## Структура кода

```
app/src/main/java/app/tvplayer/
├── MainActivity.kt            главный экран (продолжить просмотр, открыть файл)
├── data/PlaybackHistory.kt    позиции и история просмотра
├── player/
│   ├── PlayerActivity.kt      жизненный цикл, intent → плеер, результат для Lampa
│   ├── PlaybackRequest.kt     разбор intent (MX/VLC/Vimu extras)
│   ├── PlayerFactory.kt       настройка ExoPlayer (FFmpeg, буфер, HTTP)
│   ├── PlayerStateHolder.kt   состояние плеера для Compose
│   └── ui/                    оверлей, панели выбора дорожек, ошибки
└── ui/                        тема и общие TV‑компоненты
```

## Сборка

Окружение: JDK 17 (`~/.jdks/jdk-17.0.20.1+1`), Android SDK (`%LOCALAPPDATA%\Android\Sdk`).
Путь проекта содержит кириллицу, поэтому в `gradle.properties` стоит `android.overridePathCheck=true`.

```
set JAVA_HOME=%USERPROFILE%\.jdks\jdk-17.0.20.1+1
gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
gradlew assembleRelease      # ужатый APK (~8 МБ), подписан debug-ключом
adb connect <ip-приставки>
gradlew installDebug
```

Проект также открывается в Android Studio как есть.
