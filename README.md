# Smart Player

Видеоплеер для Android TV, заточенный под торренты (TorrServer) и работу в связке с Lampa.

## Скачать

Готовый APK — на странице [Releases](../../releases/latest). Установка на приставку:
скопируйте APK на флешку и откройте его файловым менеджером (например, X-plore),
разрешив установку из неизвестных источников.

В Lampa: настройки плеера → внешний плеер Android → при запуске фильма выбрать
**Smart Player** → «Всегда».

## Версия для Windows

На странице [Releases](../../releases/latest):
- `SmartPlayer-…-setup.exe` — установщик (Program Files, ярлыки, «Открыть с помощью» для видео);
- `SmartPlayer-…-windows-x64.zip` — без установки: распакуйте и запустите `SmartPlayer.exe`.

Интерфейс плеера — тот же, что на TV; видеодвижок — [mpv](https://mpv.io).

- Главное окно: «Продолжить просмотр», раздачи TorrServer, открыть файл, вставить magnet-ссылку
- Клавиши как пульт: пробел/Enter — пауза, ← → — перемотка, ↓ — меню, Esc — назад, F — полный экран, A/S — звук/субтитры
- Мышь: клик — пауза, двойной клик — полный экран, колесо — громкость
- **Lampa для ПК подключается сама.** В конце установки оставьте галочку «Launch Smart Player» — программа
  пропишет себя в Lampa как плеер для торрентов (если Lampa открыта, предложит кнопку «Подключить к Lampa»:
  Lampa закроется на пару секунд и откроется снова). То же — в Настройках Smart Player.
  Вручную: в Lampa Настройки → «Плеер для торрентов» → внешний, путь — `C:\Program Files\SmartPlayer\mpc-hc64.exe`.
  Именно `mpc-hc64.exe`, не `SmartPlayer.exe`: Lampa запускает только плееры из своего списка имён.
  Это тот же Smart Player в режиме совместимости с MPC-HC — Lampa передаёт позицию старта и сохраняет прогресс

## Возможности

- Media3 ExoPlayer + FFmpeg: MKV/MP4/AVI/TS, HLS/DASH, H.264/HEVC/AV1/HDR, звук AC3/E-AC3/DTS/TrueHD
- Внешний плеер для Lampa: extras в формате MX Player / VLC / Vimu, возврат позиции просмотра
- Управление с пульта: OK — пауза, ◀ ▶ — перемотка с ускорением, ▼ — меню
- Выбор звука и субтитров, режим кадра, скорость; лента серий и карточка «Далее»
- Auto Frame Rate — переключение частоты экрана под частоту кадров фильма
- Запоминание позиции и «Продолжить просмотр»
